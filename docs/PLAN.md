# План разработки «Тридевятое: Сказитель»

## Решение
UE5 нельзя собрать и задеплоить из облака, поэтому вертикальный срез сделан в браузере (Three.js): его можно сразу дать поиграть по ссылке, проверить «замануху» и только потом переносить в UE5.

## Этап 1 — вертикальный срез (сделано, v0.1)
- [x] Остров Лукоморье, cel-shading, серый→цветной мир
- [x] Иван: движение, удар, блок, «Удача дурака»
- [x] Сказительский взгляд + ресурс «Слово» + костёр
- [x] Нити Сказа к трём звеньям цепи
- [x] Квест «Цепь златая»: загадки, бой, рассмешить Кикимору
- [x] Сцена восстановления, Книга Сказов, забытое слово, сохранения, звук
- [ ] Деплой на GitHub Pages (ждёт токен)

## Этап 2 — альфа в браузере
- Дремучий лес: Баба-Яга забыла имя (ступа, метла, избушка — закон имени), Леший (запутать), босс «Избушка на курьих ножках»
- Переключение героев: Василиса (разгадка, зелья)
- Крафт через «пересказ», шкала доверия NPC, «Сказка на ночь»
- Мобильное управление, настройки, озвучка кота

## Этап 3 — перенос в UE5
- Перенос данных квестов/диалогов в DataTables (JSON уже отделяем от кода)
- Системы: Character, Thread, Quest, Combat, Save
- Арт: Blender, стилизация под лубок/хохлому, Niagara для нитей

## Этап 4 — бета и релиз
Все биомы, Царство Кощея, три финала, плейтесты с детьми 8–16.
