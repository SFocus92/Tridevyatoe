# Тридевятое: Сказитель — вертикальный срез

Добрая 3D-сказка, где ты спасаешь сказки от забвения. Это **играбельный браузерный прототип** (Фаза 1 из GDD): проверяем, что ядро — Нити Сказа и «оживание» мира — работает и не скучно 15 минут. Дальше механики переносятся в Unreal Engine 5.

## Что внутри
- **Лукоморье**: остров, дуб, златая цепь, кот учёный, русалка на ветвях, болото Кикиморы, берёзовая роща, костёр, портал в Дремучий лес.
- **Иван-дурак**: ходьба, прыжок, удар, блок, **«Удача дурака»** (случайный бафф — от богатырской силы до смеющихся ворон).
- **Сказительский взгляд (Q)**: тратит «Слово», показывает золотые Нити Сказа, тайники и слабости врагов (урон ×2).
- **Мир серый → цветной**: каждое найденное звено возвращает часть цвета, восстановление цепи — «взрыв» цвета, музыка, бабочки, цветы.
- **Квест «Цепь златая»** на трёх законах сказки: 3 загадки русалки (закон трёх), бой с забудками, рассмешить Кикимору (закон добра — силой её не взять).
- **Книга Сказов (B)**, **забытое слово** (кот ошибается в Пушкине — поймай его), сохранение в браузере, смерть = «засыпание» у костра.
- Процедурная музыка «гусли» и звуки (Web Audio), без внешних ассетов.

## v0.2 — «Пять сказок Лукоморья»
- **Ассеты:** Kenney Nature Kit (CC0) — сосны, лиственные деревья, камни, кусты, грибы, цветы, трава, кувшинки; свои берёзы с чёрными полосками. Всё перекрашено в лубочную палитру и тоже «серееет» без сказки.
- **Новые сказки:** «Репка» (мини-игра «тянем-потянем», мышка-норушка видна только взглядом), «По щучьему велению» (отпусти щуку — получишь телепорт T), «Колобок» (догони и не съешь — станет проводником), «Перья Жар-птицы» (7 перьев, 3 скрыты), «Камень на распутье» (прочти трижды — закон трёх).
- **Книга Сказов** 5 сказов, **забытые слова** 3 из 5, секретный разговор с котом за все сказы.
- **Красота:** небо-градиент, облака, контур персонажей (cel-look), камера не прячется за деревьями.
- **Удобство:** миникарта с целью, сенсорное управление для телефона, настройки (громкость, чувствительность), сохранение.

## Управление
WASD — идти · Shift — бег · Пробел — прыжок · мышь — камера (клик захватывает) · ЛКМ/J — удар · ПКМ/K — блок · Q — взгляд · R — удача · F — действие · B — книга · T — щучье веление · P — настройки. На телефоне — джойстик и кнопки.

## Запуск
Статический сайт, сборка не нужна:
```bash
python3 -m http.server 8000   # затем http://localhost:8000
```
Деплой: push в `main` → GitHub Actions публикует на GitHub Pages (`.github/workflows/pages.yml`). В настройках репозитория: Settings → Pages → Source: GitHub Actions.

## Структура

```
src/audio.js  — процедурный звук и музыка
vendor/       — three.js r186
docs/PLAN.md  — план разработки
```
Персонажи и сюжеты русских народных сказок и стихи Пушкина — общественное достояние. Весь визуал — собственный.
